Evidence-Centered Scoring

Skill evidence is canonicalized through alias and implication constraints, then modulated by authenticity, confidence, and target relevance gates to avoid keyword-only false positives.

Tenant Isolation

Relational and semantic layers are tenant-scoped. Candidate and shortlist queries, persistence, and semantic retrieval paths are isolated by tenant context from auth claims.

GitHub Depth Intelligence

Repository analysis includes language composition, dependency detection, contribution retention checks, commit/PR behavior, and role-context scoring tuned for job versus internship ranking.

Progressive Shortlist UX

Frontend shortlist flow shows real-time progress stages, partial completions, and final ranked output with transparent per-candidate score breakdown and decision hints.

Deployment Flexibility

Local development supports Dockerized PostgreSQL and optional Qdrant. Backend remains functional when semantic index is disabled, preserving core shortlist behavior.

Ops-Friendly Behavior

Startup includes DB connectivity checks and migration-driven schema evolution. Error paths are designed for deterministic API behavior and controlled fallback where feasible.
